Sub-steps are sorted by Name using string comparison, but names contain numeric suffixes like process_sessions.0, process_sessions.1, etc. For 10+ iterations, lexicographic ordering places process_sessions.10 before process_sessions.2, producing incorrect display order. The comment on line 141 says "sorted by index" but the implementation sorts by string. Since the integer index is already available as the map key in subStepDurations[name] (map[int]int64), sorting numerically by index would be correct.
