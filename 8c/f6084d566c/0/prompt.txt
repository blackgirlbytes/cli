### Step 6: Add E2E wall-clock timing script (`mise run bench:enable`)

**File:** `mise.toml` — new task `bench:enable`

A shell script that measures real wall-clock time of the full compiled `entire enable --agent claude-code` binary in a fresh git repo. This captures the true end-to-end startup time including process launch, Go runtime init, and all I/O — not just the Go function internals.

The script:
1. Builds the `entire` binary once via `mise run build`
2. Creates a temp git repo with an initial commit
3. Runs `entire enable --agent claude-code --telemetry=false` N times (default 10), capturing wall-clock time via Go's `time` or the built-in `time` command
4. Reports min/median/max/mean times
5. Cleans up

This is non-deterministic but gives a clear before/after signal. Run it on main first, note the numbers, then run on the feature branch.

```toml
[tasks."bench:enable"]
description = "Measure wall-clock time of 'entire enable' in a fresh repo"
run = """
#!/usr/bin/env bash
set -euo pipefail

RUNS="${BENCH_RUNS:-10}"

echo "=== Building entire binary ==="
mise run build

ENTIRE="$(pwd)/entire"
if [ ! -x "$ENTIRE" ]; then
  echo "Build failed — binary not found"
  exit 1
fi

tmpdir=$(mktemp -d)
trap 'rm -rf "$tmpdir"' EXIT

times=()
for i in $(seq 1 "$RUNS"); do
  # Fresh repo each run
  dir="$tmpdir/repo-$i"
  mkdir -p "$dir"
  git -C "$dir" init -q
  git -C "$dir" commit --allow-empty -m "init" -q

  # Measure wall-clock time (milliseconds)
  start=$(python3 -c 'import time; print(int(time.time()*1000))')
  (cd "$dir" && "$ENTIRE" enable --agent claude-code --telemetry=false) >/dev/null 2>&1
  end=$(python3 -c 'import time; print(int(time.time()*1000))')
  elapsed=$((end - start))
  times+=("$elapsed")
  printf "  Run %2d: %d ms\n" "$i" "$elapsed"
done

# Stats via python
printf "\n=== Results (%d runs) ===\n" "$RUNS"
python3 -c "
import statistics
t = [$(IFS=,; echo "${times[*]}")]
print(f'  Min:    {min(t)} ms')
print(f'  Median: {int(statistics.median(t))} ms')
print(f'  Mean:   {int(statistics.mean(t))} ms')
print(f'  Max:    {max(t)} ms')
print(f'  Stdev:  {int(statistics.stdev(t))} ms')
"
"""
```

Usage: Run on main first to get a baseline, then on the feature branch to compare.

```bash
# On main
git stash && git checkout main
mise run bench:enable    # note the median
git checkout - && git stash pop

# On feature branch (after optimizations)
mise run bench:enable    # compare median
```
