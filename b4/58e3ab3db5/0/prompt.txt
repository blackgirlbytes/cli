listTempFiles and deleteTempFiles call os.OpenRoot(paths.EntireTmpDir) where paths.EntireTmpDir is the relative path ".entire/tmp". The old code resolved this to an absolute path via paths.AbsPath(ctx, paths.EntireTmpDir), which joins it with the worktree root. The new code resolves it relative to the current working directory, so temp file listing and deletion silently fail when running from a subdirectory. Note that deleteTempFiles marks ctx as unused (_ context.Context) confirming the path resolution was dropped.

os.OpenRoot(paths.EntireTmpDir) on line 449 returns an error when .entire/tmp/ doesn't exist, causing the function to return early at line 451. The os.IsNotExist check at line 480 is unreachable in this case because it only catches WalkDir errors. The old code checked os.IsNotExist right after os.ReadDir and gracefully returned nil, nil. Now every entire clean --all invocation in a repo without .entire/tmp/ prints a spurious "Warning: failed to list temp files" message.
