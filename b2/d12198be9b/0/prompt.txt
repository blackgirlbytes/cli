## Critical (must fix)

1. *Cloud HTTP client has no default timeout.* cmd/entire/cli/dispatch/cloud.go:36-42 — NewCloudClient only honors cfg.Timeout > 0; the production caller (mode_cloud.go:64) never supplies one. Commit 0413e570f ("Fix dispatch cloud scope and timeout") actively removed the previous 30s default, and TestNewCloudClient_DefaultHTTPClientHasNoTimeout (cloud_test.go:127) locks that in. Context cancellation via NewRequestWithContext works, but cobra commands have no deadline by default, so a hung/slow server hangs the CLI until the user interrupts. Restore a sensible default (30–60s) or wrap in context.WithTimeout.

2. *Voice is sanitized in local mode only; cloud mode forwards it raw.* mode_cloud.go:72 sets Voice: opts.Voice from the unfiltered flag, while local runs sanitizeDispatchVoice (generate.go:114). Control chars / bidi / zero-width chars go straight to /api/v1/dispatch. If the stated intent is "untrusted input", sanitize at the edge regardless of mode.

## Important (should fix)

3. *sanitizeDispatchVoice collapses presets into one line.* generate.go:193-204 uses strings.Fields + Join(" "), stripping all newlines — so ResolveVoice("marvin") loses its bullet layout before reaching the model. Strip disallowed runes per-code-point, preserve \n.

4. *Tag-smuggling protection is case-sensitive.* escapeDispatchPrompt (generate.go:184-191) only rewrites exact lowercase <dispatch_data / </dispatch_data (same for voice_preference). <DISPATCH_DATA> or newline-interrupted variants pass through. Use a case-insensitive regex.

5. *Test coverage aimed at the wrong surface.* generate_test.go:49 only tests voice-field injection. No test covers a </dispatch_data> smuggled through a *checkpoint bullet* (outcome / commit subject) — the actual untrusted-input surface. Add one.

6. *Unbounded goroutine fan-out in wizard repo discovery.* dispatch_wizard.go:557-568 spawns one git rev-parse per sibling directory containing .git/. In ~/src-style monorepos this is N concurrent git processes. Cap via errgroup.SetLimit or a semaphore.

7. *Error body from non-2xx responses is printed verbatim.* cloud.go:140 interpolates the trimmed body into fmt.Errorf(...: %s, ...). Untrusted bytes can include control chars / ANSI and corrupt terminal output. Use strconv.Quote or escape.

8. *Asymmetric time normalization.* runLocal (mode_local.go:46) normalizes since/until to minute boundaries; runServer (mode_cloud.go:37) does not. Pick one semantic.

9. *Unknown server fields silently swallowed.* CreateDispatchResponse (cloud.go:61-67) doesn't model totals/warnings that tests reference. json.Decoder ignores unknown fields by default — schema drift is invisible. Consider DisallowUnknownFields() or a debug log.

10. *Package split is inconsistent.* Root-level dispatch.go owns pure flag parsing (resolveDispatchOptions, normalizeDispatchScopeValues) with no TUI deps; this belongs in cmd/entire/cli/dispatch/ next to Options. Keep only the cobra shell + huh/bubbletea glue at root.
