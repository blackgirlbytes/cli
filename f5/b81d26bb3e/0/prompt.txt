`logging.Init` is called before the git repository check in `clean.go`'s `RunE`. When run outside a git repo, `logging.Init` falls back to `repoRoot = "."` and creates a `.entire/logs/` directory in the current working directory. The `reset.go` code explicitly guards against this with the comment "Check if in git repository before initializing logging, to avoid creating .entire/logs in arbitrary directories" — but `clean.go` does it in the reversed order.

Affected files: cmd/entire/cli/clean.go:55-60, cmd/entire/cli/reset.go:23-28
