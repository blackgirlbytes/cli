1. High: the pending review marker can be claimed by the wrong session in the same worktree. `PendingReviewMarker` records both `AgentName` and `StartingSHA`, but `adoptPendingReviewMarkerInto` only checks `Kind == ""` and `WorktreePath` before tagging the session as `agent_review` and clearing the marker. That means any session that starts first in that worktree, even from a different agent or after HEAD has moved, can steal the marker and permanently attach the review metadata to the wrong checkpoint. See [review.go](/Users/soph/Work/entire/devenv/cli/cmd/entire/cli/review.go:47), [review.go](/Users/soph/Work/entire/devenv/cli/cmd/entire/cli/review.go:166), and the adoption call site in [lifecycle.go](/Users/soph/Work/entire/devenv/cli/cmd/entire/cli/lifecycle.go:265).

2. Medium: `entire review --edit` can silently delete manual review configuration for agents the picker does not surface. `runReviewConfigPicker` only builds `selected` from installed agents that have curated entries, then `saveReviewConfig` replaces `s.Review` wholesale with that reduced map. Any manually configured entries for external agents, uncurated agents, or temporarily uninstalled agents are dropped on save, despite the command comments saying those agents should be configured by editing `settings.json` directly. See [review.go](/Users/soph/Work/entire/devenv/cli/cmd/entire/cli/review.go:201), [review.go](/Users/soph/Work/entire/devenv/cli/cmd/entire/cli/review.go:259), and [review.go](/Users/soph/Work/entire/devenv/cli/cmd/entire/cli/review.go:780).

3. Medium: `--track-only` review markers are not bound to the commit they were created for, so delayed/manual review runs can be attached to the wrong code state. The marker stores `StartingSHA` when `entire review` runs, but adoption never verifies that the session still starts from that commit. If the user commits, rebases, or otherwise moves HEAD before the manual agent session begins, the later session is still tagged as the earlier review request and will condense onto a different checkpoint than the one the command was invoked for. The field is written in [review.go](/Users/soph/Work/entire/devenv/cli/cmd/entire/cli/review.go:483) and never consulted in [review.go](/Users/soph/Work/entire/devenv/cli/cmd/entire/cli/review.go:166).
