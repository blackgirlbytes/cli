Static table column widths assume wrong gap size
Low Severity

renderSearchStatic uses double-space separators ("  ") between columns (8 total characters for 4 gaps), but computeColumns subtracts only gaps = 4 (assuming single-space separators) when computing the remaining width for branch and prompt columns. This causes the static/accessible-mode table to overflow the terminal width by 4 characters, leading to unintended line wrapping in accessible mode output.
