  marvin/worktrees/cli/entire-learn/mise-tasks/learn/regenerate:23 no longer
  provides the atomic-write guarantee its comment promises.  mktemp  creates

  still leave  learn.md  truncated or partially rewritten, which is exactly
  the failure mode this script claims to prevent. Create the temp file in
   cmd/entire/cli/learn/embedded/  and rename within that directory.
