Double check this one:

EOF on empty input triggers update instead of skip

Medium Severity

When a user presses Ctrl+D (EOF) on an empty input buffer, ReadString('\n') returns ("", io.EOF). Then parseBrewUpdateChoice("") matches the case "" branch and returns (autoUpdateActionUpdate, true). Because ok is true, the function returns the update action before reaching the EOF check at lines 141-143. This means Ctrl+D — the standard "cancel/exit" signal — inadvertently triggers brew upgrade instead of skipping. The intended EOF→skip fallback is effectively dead code for the most common EOF scenario (empty buffer).
