When running "entire enable" or "entire configure", after one or more agents were enabled, check if the current directory has a .vercel director or vercel.json/vercel.ts file. If so, check if the vercel.json already has the deployment disabled for entire/* branches. If not, ask the user if they want to disable this. If so, add the following to the vercel.json (or generate a new one):
"git": {
    "deploymentEnabled": {
      "entire/*": false
    }
  }
Make sure to properly merge this with any existing config in the .json file.
