[P2] Preserve stdout/exec detail for non-envelope Claude failures — /Users/gtrrz-victor/wks/cli/cli/cmd/entire/cli/agent/claudecode/generate.go:81-86
    When cmd.Run() fails and stdout does not contain a parseable is_error envelope, this branch now classifies the failure from stderr alone. The previous helper
    fell back to stdout and finally err.Error(), so cases like a broken/incompatible claude binary or a non-zero exit that reports its error on stdout now collapse
    into ClaudeErrorUnknown with an empty message, and entire explain --generate ends up telling the user there is “no diagnostic detail”. Please keep stdout and
    the original exec error as fallbacks here so these failures stay actionable.
