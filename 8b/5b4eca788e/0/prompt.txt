This spawns git diff with context.Background() and no timeout. Elsewhere the codebase wraps git CLI calls with a bounded context (e.g. cmd/entire/cli/status.go:417-419) to avoid hooks hanging indefinitely. Consider threading the caller’s ctx into workingTreeMatchesCommit (or creating a short context.WithTimeout) before executing git diff.
