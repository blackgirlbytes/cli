# Fix: Stale ACTIVE sessions condensed into every commit

## Context

Checkpoint `6e19340bc0c8` on `entire/checkpoints/v1` contains 7 unrelated sessions (PR reviews, merge conflicts, logging work) all condensed together. Root cause: when an agent is killed without the Stop hook firing, its session remains in ACTIVE phase permanently. PostCommit unconditionally sets `hasNew = true` for ACTIVE sessions (line 611-612) and skips the `filesOverlapWithContent` check (line 494), so stale ACTIVE sessions get condensed into every commit.

PR #359 fixed this for **IDLE** sessions but left stale **ACTIVE** sessions unaddressed.

## Fix

### File: `cmd/entire/cli/strategy/manual_commit_hooks.go`

**1. Pass `filesTouchedBefore` to the handler** (around line 645)

Add a `filesTouchedBefore` field to `postCommitActionHandler`. Set it from the already-computed `filesTouchedBefore` variable (line 630-634), which includes transcript-extracted files for ACTIVE sessions.

**2. Apply overlap check in `HandleCondense` for ALL sessions** (line 487-503)

Current:
```go
shouldCondense := h.hasNew
if shouldCondense && !state.Phase.IsActive() {
    shouldCondense = filesOverlapWithContent(h.repo, h.shadowBranchName, h.commit, state.FilesTouched)
}
```

Change to:
```go
shouldCondense := h.hasNew
if shouldCondense {
    filesToCheck := h.filesTouchedBefore
    if len(filesToCheck) > 0 {
        shouldCondense = filesOverlapWithContent(h.repo, h.shadowBranchName, h.commit, filesToCheck)
    }
    // When filesToCheck is empty (transcript extraction failed + no SaveChanges yet),
    // trust hasNew to avoid data loss for mid-turn commits.
}
```

Key behavior changes:
- **Currently active session**: `filesTouchedBefore` populated from transcript (line 632-634) -> overlap check succeeds against committed files -> condensed correctly
- **Stale ACTIVE session**: `filesTouchedBefore` populated from old transcript -> overlap check fails (different files committed) -> NOT condensed
- **ACTIVE session with empty filesTouchedBefore** (transcript extraction failed): overlap check skipped, trusts `hasNew` -> condensed (fail-open, same as current)
- **IDLE/ENDED sessions**: `filesTouchedBefore == state.FilesTouched` -> same behavior as current
