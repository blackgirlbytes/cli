## 1. Problem Analysis

There are three performance bottlenecks identified in the current code, all rooted in the same pattern: **flatten the entire tree into a flat map, modify a few entries, and rebuild the entire tree from scratch**.

### Bottleneck #1: `WriteCommitted` (committed.go, line 68)
Every call to `WriteCommitted`, `UpdateCommitted`, or `UpdateSummary` invokes `getSessionsBranchEntries()`, which calls `FlattenTree()` on the entire `entire/checkpoints/v1` tree. This tree grows linearly with every checkpoint ever committed. For a repository with 200 checkpoints, this means reading hundreds of tree objects and thousands of blob entries just to add a few files to one shard bucket.

### Bottleneck #2: `buildTreeWithChanges` (temporary.go, line 699)
Every call to `WriteTemporary` and `WriteTemporaryTask` calls `buildTreeWithChanges`, which flattens the base tree (the entire repository's HEAD tree). For a repository with 500 files, this reads every tree object in the repo just to modify 3 files.

### Bottleneck #3: `addTaskMetadataToTree` (temporary.go, line 291)
Flattens the already-rebuilt tree again to add task metadata files, then calls `BuildTreeFromEntries` again.

### Why This Is O(N) When It Should Be O(depth)

The tree structure of `entire/checkpoints/v1` is:
```
root/
  a3/                     <- shard bucket (1 of 256 possible)
    b2c4d5e6f7/           <- checkpoint dir
      metadata.json
      0/
        full.jsonl
        metadata.json
        ...
  f1/                     <- another shard bucket (UNCHANGED)
    ...
  ...
```

When adding checkpoint `a3b2c4d5e6f7`, only the `a3` subtree changes. The root tree changes because `a3`'s hash changes, but all other shard buckets (`f1`, etc.) are unchanged. The current code reads every file in every shard bucket, then rebuilds every tree object. Tree surgery instead:

1. Reads the root tree (1 tree object read)
2. Finds the `a3` entry (or creates it)
3. Reads the `a3` subtree (1 tree object read)
4. Creates the new checkpoint subtree from scratch (a few new tree objects)
5. Replaces the checkpoint entry in the `a3` subtree
6. Creates a new `a3` tree object (1 tree object write)
7. Replaces the `a3` entry in the root tree with the new hash
8. Creates a new root tree object (1 tree object write)

This is O(depth) = O(3) for the metadata branch, regardless of total checkpoints.

## 2. Core New Function: `UpdateSubtree`

### Location: `/Users/evisdrenova/code/entire/devenv/cli/cmd/entire/cli/checkpoint/tree_surgery.go` (new file)

This function performs "tree surgery" -- it modifies a subtree at a given path within an existing tree without flattening. The key insight is that you can reuse all unchanged subtree hashes.

### Function Signature

```go
// UpdateSubtree replaces or creates a subtree at the given path within an existing tree.
// It walks the tree path, replacing only the entries along the modified path.
// All sibling entries at each level retain their original hashes (no re-reading or re-building).
//
// pathSegments is the directory path split into segments (e.g., ["a3", "b2c4d5e6f7", "0"]).
// newEntries are the files to place at the leaf directory (replaces that directory's contents).
// If existingEntries is non-nil, they are merged with newEntries (existing entries not in newEntries are kept).
//
// Returns the new root tree hash.
func UpdateSubtree(
    repo *git.Repository,
    rootTreeHash plumbing.Hash,
    pathSegments []string,
    newEntries []object.TreeEntry,
    opts UpdateSubtreeOptions,
) (plumbing.Hash, error)

// UpdateSubtreeOptions configures the behavior of UpdateSubtree.
type UpdateSubtreeOptions struct {
    // MergeMode controls how entries at the leaf directory are handled.
    // ReplaceAll replaces the entire directory contents.
    // MergeKeepExisting keeps existing entries not overwritten by newEntries.
    MergeMode MergeMode

    // DeletePaths lists paths (relative to the leaf directory) to delete.
    // Only applicable when MergeMode is MergeKeepExisting.
    DeletePaths []string
}

type MergeMode int

const (
    // ReplaceAll replaces the entire leaf directory contents with newEntries.
    ReplaceAll MergeMode = iota
    // MergeKeepExisting merges newEntries into the existing leaf directory,
    // keeping entries not overwritten by newEntries (unless in DeletePaths).
    MergeKeepExisting
)
```

### Pseudocode for `UpdateSubtree`

```go
func UpdateSubtree(repo *git.Repository, rootTreeHash plumbing.Hash, pathSegments []string, newEntries []object.TreeEntry, opts UpdateSubtreeOptions) (plumbing.Hash, error) {
    if len(pathSegments) == 0 {
        // We're at the leaf: build the leaf tree from newEntries
        // (optionally merging with existing entries based on MergeMode)
        return buildLeafTree(repo, rootTreeHash, newEntries, opts)
    }

    // Read the current tree at this level
    var currentEntries []object.TreeEntry
    if rootTreeHash != plumbing.ZeroHash {
        tree, err := repo.TreeObject(rootTreeHash)
        if err != nil {
            return plumbing.ZeroHash, fmt.Errorf("failed to read tree: %w", err)
        }
        currentEntries = tree.Entries
    }

    targetDir := pathSegments[0]
    remainingPath := pathSegments[1:]

    // Find the existing subtree entry for targetDir
    var existingSubtreeHash plumbing.Hash
    found := false
    for _, entry := range currentEntries {
        if entry.Name == targetDir && entry.Mode == filemode.Dir {
            existingSubtreeHash = entry.Hash
            found = true
            break
        }
    }

    // Recurse into the subtree
    newSubtreeHash, err := UpdateSubtree(repo, existingSubtreeHash, remainingPath, newEntries, opts)
    if err != nil {
        return plumbing.ZeroHash, err
    }

    // Build a new tree at this level with the updated subtree entry
    var updatedEntries []object.TreeEntry
    replaced := false
    for _, entry := range currentEntries {
        if entry.Name == targetDir {
            // Replace with new hash
            updatedEntries = append(updatedEntries, object.TreeEntry{
                Name: targetDir,
                Mode: filemode.Dir,
                Hash: newSubtreeHash,
            })
            replaced = true
        } else {
            // Keep as-is (reuse hash -- this is the key optimization)
            updatedEntries = append(updatedEntries, entry)
        }
    }
    if !found && !replaced {
        // New directory -- append
        updatedEntries = append(updatedEntries, object.TreeEntry{
            Name: targetDir,
            Mode: filemode.Dir,
            Hash: newSubtreeHash,
        })
    }

    sortTreeEntries(updatedEntries)
    return storeTree(repo, updatedEntries)
}

func buildLeafTree(repo *git.Repository, existingTreeHash plumbing.Hash, newEntries []object.TreeEntry, opts UpdateSubtreeOptions) (plumbing.Hash, error) {
    if opts.MergeMode == ReplaceAll || existingTreeHash == plumbing.ZeroHash {
        // Just build from newEntries
        sortTreeEntries(newEntries)
        return storeTree(repo, newEntries)
    }

    // MergeKeepExisting: read existing tree, merge
    existingTree, err := repo.TreeObject(existingTreeHash)
    if err != nil {
        // If can't read, just use newEntries
        sortTreeEntries(newEntries)
        return storeTree(repo, newEntries)
    }

    // Build lookup of new entries by name
    newByName := make(map[string]object.TreeEntry, len(newEntries))
    for _, e := range newEntries {
        newByName[e.Name] = e
    }

    // Build delete set
    deleteSet := make(map[string]bool, len(opts.DeletePaths))
    for _, p := range opts.DeletePaths {
        deleteSet[p] = true
    }

    // Merge: keep existing unless overwritten or deleted
    var merged []object.TreeEntry
    for _, existing := range existingTree.Entries {
        if deleteSet[existing.Name] {
            continue
        }
        if replacement, ok := newByName[existing.Name]; ok {
            merged = append(merged, replacement)
            delete(newByName, existing.Name)
        } else {
            merged = append(merged, existing)
        }
    }
    // Add remaining new entries (ones that didn't replace existing)
    for _, e := range newEntries {
        if _, stillNew := newByName[e.Name]; stillNew {
            merged = append(merged, e)
        }
    }

    sortTreeEntries(merged)
    return storeTree(repo, merged)
}

// storeTree creates a git tree object from entries and stores it in the repo.
func storeTree(repo *git.Repository, entries []object.TreeEntry) (plumbing.Hash, error) {
    tree := &object.Tree{Entries: entries}
    obj := repo.Storer.NewEncodedObject()
    if err := tree.Encode(obj); err != nil {
        return plumbing.ZeroHash, fmt.Errorf("failed to encode tree: %w", err)
    }
    hash, err := repo.Storer.SetEncodedObject(obj)
    if err != nil {
        return plumbing.ZeroHash, fmt.Errorf("failed to store tree: %w", err)
    }
    return hash, nil
}
```

### Second Helper: `UpdateSubtreeMultiPath`

For `buildTreeWithChanges`, we need to handle multiple modified files at different paths. Rather than calling `UpdateSubtree` once per file (which would re-read the tree at each level multiple times), we group changes by directory and apply them in a single pass.

```go
// TreeChange represents a single file change within a tree.
type TreeChange struct {
    Path    string             // Full path (e.g., "src/pkg/handler.go")
    Entry   *object.TreeEntry  // New entry (nil = delete)
}

// ApplyTreeChanges applies multiple file-level changes to a tree efficiently.
// Changes are grouped by directory and applied in a single recursive pass.
// This is the optimized replacement for FlattenTree + modify + BuildTreeFromEntries
// when changes touch only a few files.
func ApplyTreeChanges(
    repo *git.Repository,
    rootTreeHash plumbing.Hash,
    changes []TreeChange,
) (plumbing.Hash, error)
```

The implementation groups changes by their first path segment, then recurses into each affected subdirectory. Unchanged subdirectories retain their hashes.

```go
func ApplyTreeChanges(repo *git.Repository, rootTreeHash plumbing.Hash, changes []TreeChange) (plumbing.Hash, error) {
    if len(changes) == 0 {
        return rootTreeHash, nil
    }

    // Read the current root tree
    var currentEntries []object.TreeEntry
    if rootTreeHash != plumbing.ZeroHash {
        tree, err := repo.TreeObject(rootTreeHash)
        if err != nil {
            return plumbing.ZeroHash, err
        }
        currentEntries = make([]object.TreeEntry, len(tree.Entries))
        copy(currentEntries, tree.Entries)
    }

    // Group changes by first path segment
    type dirChanges struct {
        subChanges []TreeChange // Changes within this subdirectory (paths stripped of first segment)
        fileChange *TreeChange  // Direct file change at this level (nil if directory)
    }
    grouped := make(map[string]*dirChanges)

    for i := range changes {
        c := changes[i]
        parts := strings.SplitN(c.Path, "/", 2)
        name := parts[0]
        if grouped[name] == nil {
            grouped[name] = &dirChanges{}
        }
        if len(parts) == 1 {
            // File at this level
            cc := c
            grouped[name].fileChange = &cc
        } else {
            // In a subdirectory
            grouped[name].subChanges = append(grouped[name].subChanges, TreeChange{
                Path:  parts[1],
                Entry: c.Entry,
            })
        }
    }

    // Apply changes to current entries
    entryMap := make(map[string]object.TreeEntry, len(currentEntries))
    for _, e := range currentEntries {
        entryMap[e.Name] = e
    }

    // Process each group
    for name, dc := range grouped {
        if dc.fileChange != nil {
            if dc.fileChange.Entry == nil {
                // Delete
                delete(entryMap, name)
            } else {
                // Add/update file
                entryMap[name] = *dc.fileChange.Entry
            }
        }
        if len(dc.subChanges) > 0 {
            // Recurse into subdirectory
            existingHash := plumbing.ZeroHash
            if existing, ok := entryMap[name]; ok && existing.Mode == filemode.Dir {
                existingHash = existing.Hash
            }
            newSubHash, err := ApplyTreeChanges(repo, existingHash, dc.subChanges)
            if err != nil {
                return plumbing.ZeroHash, err
            }
            entryMap[name] = object.TreeEntry{
                Name: name,
                Mode: filemode.Dir,
                Hash: newSubHash,
            }
        }
    }

    // Convert back to slice and store
    result := make([]object.TreeEntry, 0, len(entryMap))
    for _, e := range entryMap {
        result = append(result, e)
    }
    sortTreeEntries(result)
    return storeTree(repo, result)
}
```

### Rewrite `buildTreeWithChanges`

```go
func (s *GitStore) buildTreeWithChanges(
    baseTreeHash plumbing.Hash,
    modifiedFiles, deletedFiles []string,
    metadataDir, metadataDirAbs string,
) (plumbing.Hash, error) {
    repoRoot, err := paths.RepoRoot()
    if err != nil {
        return plumbing.ZeroHash, fmt.Errorf("failed to get repo root: %w", err)
    }

    var changes []TreeChange

    // Deleted files
    for _, file := range deletedFiles {
        changes = append(changes, TreeChange{Path: file, Entry: nil})
    }

    // Modified/new files
    for _, file := range modifiedFiles {
        absPath := filepath.Join(repoRoot, file)
        if !fileExists(absPath) {
            changes = append(changes, TreeChange{Path: file, Entry: nil})
            continue
        }
        blobHash, mode, err := createBlobFromFile(s.repo, absPath)
        if err != nil {
            continue
        }
        changes = append(changes, TreeChange{
            Path: file,
            Entry: &object.TreeEntry{
                Name: filepath.Base(file),
                Mode: mode,
                Hash: blobHash,
            },
        })
    }

    // Metadata directory files
    if metadataDir != "" && metadataDirAbs != "" {
        metaChanges, err := collectMetadataChanges(s.repo, metadataDirAbs, metadataDir)
        if err != nil {
            return plumbing.ZeroHash, fmt.Errorf("failed to collect metadata changes: %w", err)
        }
        changes = append(changes, metaChanges...)
    }

    if len(changes) == 0 {
        return baseTreeHash, nil
    }

    return ApplyTreeChanges(s.repo, baseTreeHash, changes)
}
```

Where `collectMetadataChanges` walks the metadata directory (same logic as `addDirectoryToEntriesWithAbsPath`) but returns `[]TreeChange` instead of modifying a map.

## 6. Edge Cases

### 6.1. First checkpoint on empty branch
When `ensureSessionsBranch()` creates a new orphan branch with an empty tree, `rootTreeHash` is the hash of an empty tree. `UpdateSubtree` handles this correctly because when `rootTreeHash` is zero or the tree has no entries, it creates new entries at each level.

### 6.2. Multi-session checkpoints
The `buildCheckpointSubtreeEntries` function reads the existing checkpoint tree at the shard path to detect existing sessions. It uses `tree.Tree("a3").Tree("b2c4d5e6f7")` to get the existing checkpoint tree, reads `metadata.json` for the `CheckpointSummary`, determines the session index (matching existing or new), and builds the session subtree. The `MergeKeepExisting` merge mode ensures that other sessions' subdirectories are preserved.

### 6.3. Task checkpoints
Task checkpoint files go under `tasks/<toolUseID>/` within the checkpoint subdirectory. The `buildCheckpointSubtreeEntries` function includes these entries in the leaf tree. For `addTaskMetadataToTree` in the temporary path, this becomes a `TreeChange` at the appropriate path.

### 6.4. `reaggregateFromEntries` needs the flat entries
The `reaggregateFromEntries` function reads session metadata blobs from the flat entries map. In the new approach, we read session metadata directly from the existing checkpoint tree (which we already fetched for finding the session index). This avoids needing the flat map.

### 6.5. `findSessionIndex` needs the flat entries
Same as above -- reads from the existing checkpoint tree directly, not the flat map.

### 6.6. Stale file cleanup in `writeSessionToSubdirectory`
Currently lines 300-304 of committed.go delete all existing entries at a session path to prevent stale files. In the tree surgery approach, when we build the session subdirectory, we use `ReplaceAll` merge mode for the session subfolder, which naturally replaces all contents.

### 6.7. `copyMetadataDir`
This function walks a filesystem directory and adds blobs. In the new approach, it produces entries that get added to the session subtree being built.

## 7. Backward Compatibility

The tree surgery approach produces the **exact same tree structure** as the flatten+rebuild approach. The only difference is how the tree is constructed in memory:
- Same blob hashes (content is identical)
- Same tree structure (same directory hierarchy)
- Same tree hashes at every level (git tree hashes are content-addressed; same entries = same hash)

This means:
- `ReadCommitted`, `ReadSessionContent`, `ListCommitted` work without changes
- `ReadTemporary`, `GetTranscriptFromCommit` work without changes
- The `entire/checkpoints/v1` branch format is identical
- Shadow branch tree format is identical

### Keeping `FlattenTree` and `BuildTreeFromEntries`

These functions are used by external callers (push_common.go, cleanup.go, content_overlap_test.go, session_test.go) and should be kept as-is. The new tree surgery functions are **additions**, not replacements. The old functions remain available for use cases where a full flatten+rebuild is the appropriate pattern (e.g., merge in push_common.go where two full trees need to be combined).

## 10. Key Design Decisions and Tradeoffs

**Decision 1: Two separate APIs (`UpdateSubtree` and `ApplyTreeChanges`)**
- `UpdateSubtree` is optimized for the metadata branch case: replacing one directory deep in a tree.
- `ApplyTreeChanges` is optimized for the working tree case: modifying scattered files across the tree.
- Both avoid the flatten+rebuild pattern.

**Decision 2: Keep `FlattenTree`/`BuildTreeFromEntries` alongside new functions**
- External callers (push_common.go, cleanup.go) use flatten+rebuild for legitimate reasons (merging two full trees, deleting scattered checkpoints).
- No breaking changes to the public API.

**Decision 3: `MergeKeepExisting` mode for checkpoint writes**
- When writing a checkpoint to an existing shard bucket, other checkpoints in that bucket must be preserved.
- The `MergeKeepExisting` mode handles this naturally.

**Decision 4: Read existing checkpoint tree for session indexing**

         pathSegments []string,
         newEntries []object.TreeEntry,

                     Mode: filemode.Dir,
                     Hash: newSubtreeHash,
                 })
                 replaced = true
             } else {
                 updatedEntries = append(updatedEntries, entry)
             }
         }
         if !found && !replaced {

                 Name: targetDir,
                 Mode: filemode.Dir,
                 Hash: newSubtreeHash,
             })
         }
         sortTreeEntries(updatedEntries)
         return storeTree(repo, updatedEntries)

         if opts.MergeMode == ReplaceAll || existingTreeHash == plumbing.ZeroHash {
             sorted := make([]object.TreeEntry, len(newEntries))
             copy(sorted, newEntries)
             sortTreeEntries(sorted)
             return storeTree(repo, sorted)

     func (s *GitStore) flattenCheckpointEntries(rootTreeHash plumbing.Hash, checkpointPath string) (map[string]object.TreeEntry, error) {
         entries := make(map[string]object.TreeEntry)
         if rootTreeHash == plumbing.ZeroHash {
             return entries, nil
         }
         rootTree, err := s.repo.TreeObject(rootTreeHash)
         if err != nil {
             return entries, nil
         }
         subtree, err := rootTree.Tree(checkpointPath)
         if err != nil {
             return entries, nil
         }
         if err := FlattenTree(s.repo, subtree, checkpointPath, entries); err != nil {
             return nil, err

         return entries, nil

     func (s *GitStore) spliceCheckpointSubtree(rootTreeHash plumbing.Hash, checkpointID id.CheckpointID, basePath string, entries map[string]object.TreeEntry) (plumbing.Hash, error) {
         relEntries := make(map[string]object.TreeEntry, len(entries))
         for path, entry := range entries {
             relPath := strings.TrimPrefix(path, basePath)
             if relPath == path {
                 continue
             }
             relEntries[relPath] = entry
         }
         checkpointTreeHash, err := BuildTreeFromEntries(s.repo, relEntries)
         if err != nil {
             return plumbing.ZeroHash, fmt.Errorf("failed to build checkpoint subtree: %w", err)

         shardPrefix := string(checkpointID[:2])
         shardSuffix := string(checkpointID[2:])
         return UpdateSubtree(s.repo, rootTreeHash, []string{shardPrefix}, []object.TreeEntry{
             {Name: shardSuffix, Mode: filemode.Dir, Hash: checkpointTreeHash},
         }, UpdateSubtreeOptions{MergeMode: MergeKeepExisting})
