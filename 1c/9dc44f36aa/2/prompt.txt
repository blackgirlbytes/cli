## Reference: Gemini CLI pattern

Follow `geminicli/transcript.go` + `geminicli/gemini.go:201-277` + `geminicli/lifecycle.go:16` as the reference implementation. Kiro's format is similar (single JSON blob) but uses paired history entries instead of a flat messages array.

## Kiro Transcript Format (from real SQLite cache)

```json
{
  "conversation_id": "uuid",
  "history": [
    {
      "user": { "content": { "Prompt": { "prompt": "text" } }, "timestamp": "..." },
      "assistant": { "Response": { "message_id": "uuid", "content": "text" } }
    },
    {
      "user": { "content": { "Prompt": { "prompt": "text" } } },
      "assistant": { "ToolUse": { "message_id": "uuid", "tool_uses": [
        { "id": "tu-1", "name": "fs_write", "args": { "path": "/abs/path/file.go", ... } }
      ]}}
    },
    {
      "user": { "content": { "ToolUseResults": { "tool_use_results": [...] } } },
      "assistant": { "Response": { "message_id": "uuid", "content": "Done." } }
    }
  ]
}
```

- Position = `len(history)` (each entry is a user+assistant pair)
- User content is tagged union: `Prompt` or `ToolUseResults`
- Assistant content is tagged union: `Response` (text) or `ToolUse` (tool calls)
- File modification tool: `fs_write` (observed), `fs_edit` (defensive)
- Tool args: `path` field has absolute paths

## Implementation Steps

### 1. Add transcript types to `types.go`

Unexported types (package-internal, following existing pattern):

- `kiroTranscript` — top-level: `conversation_id` + `history []kiroHistoryEntry`
- `kiroHistoryEntry` — `user kiroUserMessage` + `assistant json.RawMessage`
- `kiroUserMessage` — `content json.RawMessage` + `timestamp string`
- `kiroPromptContent` — for unmarshalling `{"Prompt": {"prompt": "..."}}`
- `kiroToolUseContent` — for unmarshalling `{"ToolUse": {...}}`
- `kiroResponseContent` — for unmarshalling `{"Response": {...}}`
- `kiroToolUsePayload` — `message_id`, `tool_uses []kiroToolCall`
- `kiroResponsePayload` — `message_id`, `content`
- `kiroToolCall` — `id`, `name`, `args json.RawMessage`

Use `json.RawMessage` for the tagged unions (user content, assistant content, tool args) — try each variant in helpers rather than custom UnmarshalJSON.

### 2. Create `transcript.go` with parse helpers and constants

File modification tools constant:
```go
var kiroFileModificationTools = []string{"fs_write", "fs_edit"}
```

Pure functions (no methods on KiroAgent):
- `parseTranscript(data []byte) (*kiroTranscript, error)`
- `extractUserPrompt(content json.RawMessage) string` — returns prompt text or ""
- `extractModifiedFilesFromHistory(entries []kiroHistoryEntry) []string` — deduped file paths
- `isFileModificationTool(name string) bool`
- `extractFilePath(args json.RawMessage) string` — checks `path`, `file_path`, `filename`
- `extractLastAssistantResponse(entries []kiroHistoryEntry) string` — walks backward for last Response

### 3. Add TranscriptAnalyzer methods to `kiro.go`

All four methods on `*KiroAgent`, following the Gemini pattern (read file → parse → extract):

- **`GetTranscriptPosition(path)`** → `len(t.History)`, return 0 for missing/empty/`{}`
- **`ExtractModifiedFilesFromOffset(path, startOffset)`** → slice `t.History[startOffset:]`, extract file paths via `extractModifiedFilesFromHistory`
- **`ExtractPrompts(sessionRef, fromOffset)`** → iterate `t.History[fromOffset:]`, collect `extractUserPrompt` results
- **`ExtractSummary(sessionRef)`** → `extractLastAssistantResponse(t.History)`

### 4. Add compile-time assertion

In `lifecycle.go` (matching Gemini's `lifecycle.go:16`):
```go
var _ agent.TranscriptAnalyzer = (*KiroAgent)(nil)
```

Update `kiro_test.go:16-19` to add the assertion there too.

### 5. Add tests in `transcript_test.go`

Table-driven tests with `t.Parallel()` and `t.Run`:

- `TestParseTranscript` — valid, empty history, `{}`, invalid JSON
- `TestExtractUserPrompt` — Prompt variant, ToolUseResults variant, empty
- `TestExtractModifiedFilesFromHistory` — fs_write paths, non-file tools skipped, dedup
- `TestGetTranscriptPosition` — empty path, missing file, empty file, placeholder `{}`, normal
- `TestExtractModifiedFilesFromOffset` — offset 0, offset > 0, offset >= len, missing file
- `TestExtractPrompts` — all prompts, with offset, skips ToolUseResults entries
- `TestExtractSummary` — last Response, skips ToolUse, empty transcript
- `TestExtractFilePath` — path field, file_path fallback, filename fallback, empty

Use a shared `testKiroTranscript` constant with 4 history entries (2 prompts, 1 tool use with fs_write, 1 tool result + final response).
