  3. Important Discoveries

  - Original 20-30min reports were rerun-dominated by the repair pass, not the migration loop itself. Fresh runs scale to ~9min for 4k checkpoints.
  - Why repair fires on near-no-op reruns: 30 freshly-migrated checkpoints land in pendingFull, the partial-generation pack at end of run trips RotateCurrentGenerationIfNeeded, which appends
  one new archived ref to freshlyPackedRefs. That single ref trips the gate at migrate.go:172 (len(freshlyPackedRefs) > 0) — repair then walks every other archived generation (~3.4 min/archive
   × ~4 archives = ~13.6min), even though those pre-existing archives are unchanged from prior runs.
  - Design pivot mid-task: initially proposed using perf.Span/LoopSpan everywhere, but LoopSpan (manual_commit_hooks.go:990) emits one iteration span per pass — at 4k+ iterations × 6 sub-spans
   each, that's 24k+ attrs in a single perf log line. Switched to a custom aggregator for per-checkpoint stages while keeping perf.Span-style timing for one-shot phases. (perf package itself
  is untouched.)
  - Minor reporting quirk: process_checkpoints phase wraps the entire migrateCheckpointsV2 call, so it nests the inner phases (list_v1_checkpoints, build_full_artifacts_index,
  pack_partial_generation). Subtract those for the loop-body-only number. Fixable but not blocking.
  - Pre-existing flake: TestResolveAgentForRewind in cmd/entire/cli/strategy/ is flaky on main too (~50% fail rate when run with the rest of the strategy suite, passes in isolation). Unrelated
   to this work.

  4. Next Steps

  Recommended priority: fix the rerun blowup (bigger user-facing win, smaller blast radius). Two reasonable approaches discussed but not yet decided:
  1. Version-tag generation.json — add e.g. "packer_version": "..." so the repair pass can skip archives already produced by the current packer. After one repair per archive, future runs are
  O(0).
  2. Tighten the gate at migrate.go:172 — only run repair against archives lacking the marker.

  Lower priority: investigate fresh-run hot path (compact_transcript 35% + pack_full_generation 35%) for sub-stage profiling, but ~9min for 4k is tolerable.
