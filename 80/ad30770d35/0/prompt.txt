  # /pr-review-toolkit:review-pr — Comprehensive Multi-Agent Review

  Three specialized passes ( code-reviewer ,  silent-failure-hunter ,  pr-
  test-analyzer ) ran against the same scope ( origin/feat/entire-
  review...HEAD , 17 files, ~1,090 LoC added). Findings, deduplicated and
  ranked:

  ## High Priority

  ### H1.  RotateCurrentGenerationIfNeeded  archive-ref-already-exists branch
  is uncovered AND ambiguous

   cmd/entire/cli/checkpoint/v2_generation.go:511-517 

  • Test gap (high): No test exercises the path where a prior rotation crashed
  after creating the archive ref but before resetting  /full/current .
  Function returns  (archiveRefName, false, nil) .
  • Silent-failure (medium): Caller treats  false  as "no rotation, retry next
  time" — but next call rediscovers the same  archiveNumber  and loops forever
  with no error if the archive ref points at a hash that isn't  currentRef.
  Hash() .
  • Combined fix: Add a check that  archiveRef.Hash() == currentRef.Hash() 
  before treating this as benign; return a wrapped error if mismatched. Add a
  test that pre-creates the archive ref at a foreign hash and asserts the
  function returns an error rather than silently looping.

  ### H2.  evictMigratedRawArtifacts  shrinking-chunk eviction is uncovered

   cmd/entire/cli/migrate.go:679-688 

  • Test gap (high): This is the entire reason the function exists — re-
  migration with fewer chunks must remove  transcript.jsonl.1 ,  transcript.
  jsonl.2 , etc. — and there's no direct test.
  • Suggested test: Pre-populate  entries  with  cp.Path()+"/0/transcript.
  jsonl.0" ,  .1 ,  .2 , and the hash file. Call  evictMigratedRawArtifacts .
  Assert the four keys are gone, sibling sessions ( /1/... ) and other
  checkpoints survive.

  ### H3.  SignCommitBestEffort  silently re-loads signer per commit

   cmd/entire/cli/checkpoint/committed.go:1864-1902 

  • The signer is now loaded on every checkpoint commit. If  SSH_AUTH_SOCK 
  disappears mid-session, the agent restarts, or global git config is
  rewritten, subsequent checkpoints are silently unsigned — and the early
   !ok  returns at lines 1873-1879 don't even log.
  • Recommendation: at minimum, add  logging.Debug  with a stable reason code
  on each early-return so on/off transitions are observable in  .entire/logs/ .
  A small per-process cache of the signer would also let transient failures
  fail loudly once instead of silently every commit.

  ### H4. Misconfigured custom signer falls back silently at debug level

   cmd/entire/cli/checkpoint/objectsigner.go:74-78 

  • A typo or missing binary in  gpg.ssh.program=op-ssh-sign  makes
   programsigner.New  fail; we silently fall back to  auto.FromConfig . Users
  who explicitly opted in get unsigned commits with no surfaced reason.
  • Recommendation: escalate to  logging.Warn  with  signFormat  and
   programName  in attrs — this is an explicit user configuration, so a
  failure is unexpected.

  ## Medium Priority

  ### M1.  RegisterObjectSigner  deletion eliminates global signer
  registration

  • The old code registered the signer globally via  plugin.Register(plugin.
  ObjectSigner(), ...) ; any go-git commit creation could pick it up. The new
  code only signs through  SignCommitBestEffort . If anywhere outside the
  checkpoint package creates commits via go-git expecting the registered
  signer, those commits are now unsigned. Audit commit-creation sites; if
  intentional, add a one-line comment at  committed.go:1867  noting this is
  the only signing entry point.

  ### M2.  createV2FullCurrentRefIfMissing  shells out without inline
  rationale

   cmd/entire/cli/migrate.go:547-570 

  • Shelling out to  git update-ref  is legitimate (go-git's
   CheckAndSetReference  requires a non-zero old hash, so it can't express
  atomic create-only). But the next maintainer will see  exec.
  CommandContext("git", ...)  and try to "fix" it back to go-git per the v5/v6
  caveat in CLAUDE.md (which is about a different bug). Add a short  // why we
  shell out: go-git can't express create-only-if-missing semantics  comment.
  • Idempotent-success path on  git update-ref  failure ( currentRef.Hash() ==
  newHash → nil ) also lacks a forensic log line — when this branch fires it
  should leave a breadcrumb.

  ### M3.  customSignProgram  multi-scope precedence is partially tested

   cmd/entire/cli/checkpoint/objectsigner.go:115-132 

  •  TestCustomSignProgram_GlobalOverridesSystem  exists. Untested: "system
  custom + global empty → custom returned", "global custom overrides system
  custom", and the case where global sets  gpg.program=""  explicitly (git
  treats this as a reset; the current code's  if scopedProgram != ""  skip
  would not reset). Headline new behavior — add a couple of table cases.

  ### M4.  loadScopedConfig  uses  fmt.Fprintf(os.Stderr, ...)  instead of
   logging.Warn 

   cmd/entire/cli/checkpoint/objectsigner.go:181-197 

  • Pre-existing (verbatim moved from  committed.go ) but inconsistent with
  CLAUDE.md ("Don't use  fmt.Print*  for operational messages"). Output
  bypasses  .entire/logs/ , can interleave with TUI output. The relocation was
  a chance to fix it. Plumb  ctx  through and use  logging.Warn .
  •  scopeName  map only contains  Global / System  — a future caller passing
   LocalScope  would render  "warning: failed to load  git config: ..." 
  (double space). Fall back to  scope.String() .

  ### M5.  migratedFullEntrySet.mergeInto  task-no-override contract is
  uncovered

   cmd/entire/cli/migrate.go:664-674 

  • The contract — raw overrides, task does not — is documented in a comment
  but not asserted in a test. Add a 10-line direct test.

  ### M6.  loadObjectSignerFromConfigs  auto-fallback path uncovered

   cmd/entire/cli/checkpoint/objectsigner.go:52-62 

  •  commit.gpgsign=true, no gpg.program → auto signer  and  commit.
  gpgsign=false → (nil, false)  are both untested.

  ### M7.  createV2FullCurrentRefIfMissing  idempotent-retry uncovered

   cmd/entire/cli/migrate.go:547-570 

  • Pre-set ref to  newHash , call helper, expect nil. Crash-recovery path is
  load-bearing.
