When the log file doesn't exist (e.g., user runs entire perf before any hooks have been invoked), this returns a raw error like "collecting perf entries: opening perf log: open .../entire.log: no such file or directory". It would be more user-friendly to check for os.IsNotExist(err) and return an empty entries list instead, which would then trigger the helpful "No perf entries found" message with instructions on enabling DEBUG logging.
