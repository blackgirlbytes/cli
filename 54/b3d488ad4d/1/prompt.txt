# Plan: `entire dashboard` - Integrated TUI Dashboard

## Context

Currently, the entire-cli provides session/checkpoint information spread across multiple commands (`status`, `explain`, `rewind`), each with text-only output. There is no unified, interactive way to browse sessions, inspect checkpoints, view active session status, and manage settings from a single screen. This plan adds an `entire dashboard` command that provides a full-screen TUI for all of these operations.

## Architecture

### Package Structure

Create a new `cmd/entire/cli/dashboard/` package containing the bubbletea TUI. The `cli` package adds a thin cobra command wrapper in `dashboard_cmd.go`.

**Why a separate package:** Isolates TUI complexity from command logic. The dashboard package imports `strategy`, `session`, `settings`, `checkpoint` directly (no import cycles since none of these import `cli`).

**Dependency promotion:** `bubbletea`, `bubbles`, `lipgloss` are currently indirect deps (via `huh`). Promote to direct in `go.mod`.

### Layout: Tab-based with 4 tabs

```
 [Sessions] [Checkpoints] [Active] [Settings]
+--------------------------------------------+
|                                            |
|  Full-width content for selected tab       |
|                                            |
+--------------------------------------------+
 Tab/Shift+Tab: switch | j/k: navigate | Enter: detail | q: quit | ?: help
```

Tab-based layout is simpler than multi-column, works across terminal widths (min ~80 cols), and provides clear navigation.

### Keyboard Navigation

| Key | Action |
|-----|--------|
| `Tab` / `Shift+Tab` | Cycle tabs |
| `j`/`k` or Up/Down | Navigate items |
| `Enter` | View detail / expand |
| `Esc` | Close detail / clear filter |
| `/` | Search/filter |
| `r` | Rewind (checkpoints tab, with confirm) |
| `q` / `Ctrl+C` | Quit |
| `?` | Toggle help |

### 1. `cmd/entire/cli/dashboard/dashboard.go` (~250 lines)
Root bubbletea model with tab switching, resize handling, help toggle.

```go
type Model struct {
    activeTab  int
    tabs       []string
    sessions   *SessionsModel
    checkpoints *CheckpointsModel
    active     *ActiveModel
    settings   *SettingsModel
    width, height int
    help       help.Model
    showHelp   bool
    keys       keyMap

```

- `Init()` fires `tea.Batch(loadSessions, loadCheckpoints, loadActiveSessions, loadSettings)` for parallel data fetch
- `Update()` delegates to active tab model, handles tab switching + resize
- `View()` renders tab bar + active tab content + help footer

Browsable list of all sessions (historical + active).

### 10. `cmd/entire/cli/dashboard_cmd.go` (~40 lines, in `cli` package)
Cobra command registration.

```go
func newDashboardCmd() *cobra.Command {
    return &cobra.Command{
        Use:   "dashboard",
        Short: "Open interactive session dashboard",
        RunE: func(cmd *cobra.Command, _ []string) error {
            if checkDisabledGuard(cmd.OutOrStdout()) {
                return nil
            }
            if IsAccessibleMode() {
                return dashboard.RunAccessible(cmd.OutOrStdout(), cmd.ErrOrStderr())
            }
            return dashboard.Run()
        },
    }
}
```

Register in `root.go`:
```go
cmd.AddCommand(newDashboardCmd())
```

## Rewind from Dashboard

When user presses `r` on a checkpoint:
1. Show inline confirmation (not huh form - stay in bubbletea)
2. If confirmed, send `tea.Quit` with a rewind action message
3. After TUI exits, `dashboard.Run()` returns a rewind request
4. `dashboard_cmd.go` performs the rewind using existing strategy interface
5. Prints resume command (matching existing `rewind.go` behavior)

This keeps destructive operations outside the TUI for safety.
