The issue is in updateCommittedFullTranscript in v2_committed.go. Let me show you.

  writeCommittedFullTranscript (the initial write) correctly clears all entries at the session path before writing:

  // v2_committed.go:539-543
  for key := range entries {
      if strings.HasPrefix(key, sessionPath) {
          delete(entries, key)
      }
  }

  But updateCommittedFullTranscript (used by finalization and migration repair) only clears v2-named files:

  // v2_committed.go:246-255
  for key := range entries {
      switch {
      case key == rawTranscriptPath:           // raw_transcript
          delete(entries, key)
      case strings.HasPrefix(key, rawTranscriptPath+"."): // raw_transcript.001, etc
          delete(entries, key)
      case key == rawHashPath:                 // raw_transcript_hash.txt
          delete(entries, key)
      }
  }

  This doesn't clean up v1-named files (full.jsonl, full.jsonl.001, content_hash.txt). If an older version of the code wrote full.jsonl to /full/current, any
  subsequent UpdateCommitted call would write raw_transcript alongside the existing full.jsonl without removing it.
