Instead of pushing the refspecs one by one, we could generate a list of refspecs and have git do the heavy lifting for us instead of trying to parallelize the whole process:

```
refSpecs := []string{
        "refs/entire/checkpoints/v2/main:refs/entire/checkpoints/v2/main",
        "refs/entire/checkpoints/v2/full/current:refs/entire/checkpoints/v2/full/current",
        "refs/entire/checkpoints/v2/full/0000000000002:refs/entire/checkpoints/v2/full/0000000000002",
  }
```
It looks like git supports multiple refspecs at once:
```
	args := []string{"push", "--no-verify", "--porcelain"}
	args = append(args, opts.ExtraArgs...)
	args = append(args, pushTarget)
	args = append(args, opts.RefSpecs...)
```
