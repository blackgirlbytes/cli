IsPromisorRepo() caches the result via sync.Once, but the first call uses the provided ctx for git config. If that ctx is already canceled or times out, cmd.Output() will fail and the function will cache false for the rest of the process, even when later calls have a valid context. Consider running the detection with a non-cancelable context (or only caching when the command succeeds / ctx isn’t canceled), so transient context errors don’t permanently force the non-promisor path.

IsPromisorRepo() runs git config --get extensions.partialClone without --local, so a user/global gitconfig setting could incorrectly mark every repo as promisor. Using git config --local --get extensions.partialClone keeps detection scoped to the repository config and avoids false positives (and makes tests less environment-dependent).
